# AI 繪圖提示詞生成器 🎨

專為 **Gemini Nano Banana** 設計的專業 AI 繪圖提示詞生成器，讓您輕鬆創建高質量的圖像生成提示詞。

![AI 繪圖提示詞生成器](screenshot.png)

## ✨ 功能特色

### 🎯 豐富的選項類別
- **🎨 藝術風格**：寫實攝影、動漫、水彩、油畫、賽博朋克等 12 種風格
- **📷 鏡頭角度**：特寫、廣角、鳥瞰、仰視等 10 種角度
- **🖼️ 構圖方式**：三分法、對稱、黃金比例等 8 種構圖
- **💡 光線效果**：自然光、金色時刻、戲劇性光線等 10 種光線
- **✨ 氛圍情緒**：夢幻、神秘、溫馨、史詩等 10 種氛圍
- **🌈 色調**：暖色調、冷色調、霓虹色等 9 種色調
- **🔍 細節修飾**：高細節、景深、動態模糊等 8 種細節

### 💫 現代化設計
- 🌙 精美的深色主題
- 🎨 流暢的漸變色彩和動畫效果
- 📱 完全響應式設計，支持手機和桌面
- ⚡ 即時預覽生成的提示詞
- 📋 一鍵複製到剪貼板

## 🚀 使用方法

1. **選擇類別**：點擊頂部的標籤頁切換不同的選項類別
2. **選擇選項**：點擊選項卡片來選中或取消選擇
3. **預覽提示詞**：右側預覽區會即時顯示生成的完整提示詞
4. **複製使用**：點擊「複製」按鈕將提示詞複製到剪貼板
5. **清除重來**：點擊「清除」按鈕重置所有選擇

## 🌐 部署到 GitHub Pages

### 1. 創建 GitHub 倉庫

在 GitHub 上創建一個新的倉庫（例如：`ai-prompt-generator`）

### 2. 初始化並推送代碼

在專案目錄中執行以下命令：

```bash
# 初始化 Git 倉庫
git init

# 添加所有文件
git add .

# 提交更改
git commit -m "Initial commit: AI 繪圖提示詞生成器"

# 設置主分支
git branch -M main

# 添加遠程倉庫（替換成您的倉庫 URL）
git remote add origin https://github.com/您的用戶名/ai-prompt-generator.git

# 推送到 GitHub
git push -u origin main
```

### 3. 啟用 GitHub Pages

1. 進入您的 GitHub 倉庫
2. 點擊 **Settings**（設置）
3. 在左側菜單中找到 **Pages**
4. 在 **Source** 下選擇 **main** 分支
5. 點擊 **Save**（保存）
6. 等待幾分鐘後，您的網站將在 `https://您的用戶名.github.io/ai-prompt-generator/` 上線

## 💡 使用提示

### 最佳實踐
- **組合使用**：從不同類別中選擇選項，創建更豐富的提示詞
- **適度選擇**：不要選擇過多選項，保持提示詞清晰
- **實驗嘗試**：嘗試不同的組合，找到最適合您需求的提示詞
